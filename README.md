# B站视频表现驾驶舱 v1.0

一个基于真实 B 站稿件 CSV 数据构建的可视化数据看板，用于快速查看视频内容的播放表现、留存质量、互动结构和涨粉效果。

项目整体采用深色数据舱视觉风格，适合用于内容复盘、选题判断和近期视频表现对比。

## 项目预览

- 核心指标：总播放量、平均播放进度、平均互动率、总涨粉量
- 核心图表：播放量排行、播放质量象限、互动资产结构、单视频体检
- 核心交互：排序切换、视频搜索、图表与表格联动、当前数据与上一版数据对比

## 功能特性

- 基于 `CSV` 数据直接生成看板，无需额外后端
- 自动解析 B 站常见视频表现字段
- 支持读取上一版 CSV 并计算环比变化
- 支持按播放量、互动率、平均播放进度、涨粉量、封标点击率切换排序
- 提供单视频诊断视图，便于快速定位高潜内容和短板内容
- 适配桌面端与移动端基础浏览

## 本地运行



## 数据文件说明

### 当前数据

- 路径：`public/data/recent-videos.csv`
- 用途：页面默认读取的主数据源

### 对比数据

- 路径：`public/data/recent-videos-prev.csv`
- 用途：用于计算相对上一版数据的变化
- 说明：如果该文件不存在或读取失败，页面会自动降级为仅展示当前数据

### 原始参考文件

- 路径：`近期稿件对比.csv`
- 用途：项目内的数据来源参考文件，便于手动更新或重新整理 CSV

## 当前支持的主要字段

项目当前在 `src/data.ts` 中解析并使用了以下指标：

- 视频标题、发布时间
- 播放量
- 游客播放占比、粉丝观看率
- 封标点击率、粉丝点击率、游客点击率
- 3 秒跳出率及其粉丝/游客拆分
- 互动率及其粉丝/游客拆分
- 涨粉量、播转粉率、取关量
- 点赞、评论、弹幕、收藏、投币、转发及其对应比率
- 平均播放进度

如果你调整了 CSV 表头，需要同步更新 [src/data.ts](/F:/zhangbin_codex/b站数据看板1.0版本/src/data.ts) 中的 `RawVideoRow` 和解析逻辑。

## 自定义数据

如果你希望替换成自己的 B 站数据，可以按下面流程操作：

1. 准备字段结构一致的 CSV 文件。
2. 用新的数据覆盖 `public/data/recent-videos.csv`。
3. 如果需要做前后版本对比，再额外提供 `public/data/recent-videos-prev.csv`。
4. 启动项目后检查图表是否正常渲染、百分比字段是否显示正常。

## 页面说明

### 顶部 KPI 卡片

快速总览近期视频的整体表现，包括播放、留存、互动和涨粉。

### 播放量排行

展示当前视频列表的播放量排名，并支持点击条形图联动到单视频详情。

### 选中视频体检

聚焦单条视频的关键诊断信息，包括：

- 封标点击表现
- 3 秒跳出
- 平均播放进度
- 播转粉率
- 游客播放占比
- 粉丝观看率

### 播放质量象限

通过播放量、平均播放进度和互动量的组合，帮助判断内容质量与传播效率。

### 互动资产结构

拆分展示点赞、评论、弹幕、收藏、投币和转发结构，方便做互动来源分析。

### 视频明细对比表

支持按标题搜索，并在存在上一版数据时显示关键指标增减情况。

## 部署

仓库已经包含 `vercel.json`，可以直接用于 Vercel 部署。

### Vercel

```bash
npm run build
```

默认构建配置如下：

- Framework: `vite`
- Build Command: `npm run build`
- Output Directory: `dist`

如果你使用其他静态托管平台，也只需要托管 `dist/` 目录即可。

## 开发建议

- 视觉调整优先修改 [src/styles.css](/F:/zhangbin_codex/b站数据看板1.0版本/src/styles.css)
- 页面结构和交互优先修改 [src/App.tsx](/F:/zhangbin_codex/b站数据看板1.0版本/src/App.tsx)
- 数据解析、格式化和统计逻辑优先修改 [src/data.ts](/F:/zhangbin_codex/b站数据看板1.0版本/src/data.ts)

## 验证方式

建议在修改后至少执行一次：

```bash
npm run build
```

如果你改动了图表、布局或 CSV 解析逻辑，建议再额外检查：

- 页面是否能正常加载
- 图表是否渲染正常
- 搜索和联动是否可用
- 百分比与环比数据是否符合预期
- 移动端断点下是否出现明显布局错位
